# The Mean Value Theorem
2026-08-17
Math Academy
Subject: Calculus I
Topics: Differentiation

The **mean value theorem** states that for any function that is continuous and differentiable on some interval, there is some point where the derivative of the function is equal to the slope between the endpoints.

![](../assets/Pasted%20image%2020260817113315.png)

$$f^{\prime}\left(c\right)=\frac{f\left(b\right)-f\left(a\right)}{b-a}$$
